# Ipsita Bajpai - Personal Portfolio

A modern, visually stunning, fully responsive personal portfolio website built with HTML, CSS, and Vanilla JavaScript. The design features a premium **Maroon & Golden** theme with dark mode aesthetics, glassmorphism, and smooth animations.

## ✨ Features

- **Dark Mode Aesthetic**: A sleek, premium dark theme inspired by modern developer portfolios.
- **Glassmorphism**: Elegant translucent UI elements for a state-of-the-art feel.
- **Interactive Custom Cursor**: A smooth, animated cursor that reacts to interactive elements.
- **Scroll Reveal Animations**: Dynamic content loading as you scroll through the page.
- **Typing Animation**: Engaging hero subtitle showcasing core professional titles.
- **Particle Background**: Subtle, animated floating particles using HTML5 Canvas.
- **Responsive Design**: Fully optimized for desktop, tablet, and mobile devices.
- **Recruiter Friendly**: Clearly organized sections for Skills, Projects, Experience, and Certifications.

## 🛠️ Tech Stack

- **HTML5**: Semantic structure for SEO and accessibility.
- **CSS3**: Custom styling, grid/flexbox layouts, and keyframe animations.
- **JavaScript (Vanilla)**: Core logic for interactivity and scroll effects.
- **Google Fonts**: 'Inter' and 'Space Grotesk' for professional typography.
- **Font Awesome**: High-quality icons for social and UI elements.

## 🚀 Deployment (GitHub Pages)

To deploy this portfolio to your GitHub Pages:

1. **Initialize Git**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Professional Portfolio"
   ```

2. **Create a GitHub Repo**:
   - Create a new repository on GitHub named `portfolio_svnit`.
   - Copy the repository URL.

3. **Push to GitHub**:
   ```bash
   git remote add origin YOUR_REPO_URL
   git branch -M main
   git push -u origin main
   ```

4. **Enable GitHub Pages**:
   - Go to your repository **Settings** on GitHub.
   - Click on **Pages** in the left sidebar.
   - Under **Build and deployment > Branch**, select `main` and click **Save**.
   - Your site will be live at `https://your-username.github.io/portfolio_svnit/`.
