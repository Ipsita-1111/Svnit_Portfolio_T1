## 🚀 Deployment Instructions

### Method 1: GitHub Pages (Recommended)
1.  **Create a Repository**: Log in to GitHub and create a new repository (e.g., `ipsita-portfolio`).
2.  **Upload Files**: Upload `index.html`, `style.css`, and `script.js` to the repository.
3.  **Enable Pages**:
    -   Go to **Settings** > **Pages**.
    -   Under **Branch**, select `main` (or `master`) and click **Save**.
4.  **Visit Site**: Your site will be live at `https://yourusername.github.io/ipsita-portfolio/`.

### Method 2: Vercel / Netlify
1.  Drag and drop the `portfolio` folder into the Vercel or Netlify dashboard.
2.  Your site will be deployed instantly with a custom URL.

## 🎨 Customization
- **Change Colors**: Modify the CSS variables in `:root` at the top of `style.css`.
- **Add Images**: Replace the placeholders in `index.html` with your actual profile and project images.
- **Update Content**: Edit the text in `index.html` to reflect your latest achievements.
